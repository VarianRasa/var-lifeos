# Productivity feature roadmap

Goal: bring proven Notion, Obsidian, Linear, Todoist, Miro, and graph-editor workflows into Var without losing the local-first mindmap model.

## Phase 1: Knowledge graph core

Status: in progress.

- Backlinks in node editor
- Suggested compatible relations
- Drag-to-connect node graph UX
- Professional node cards
- Inline node title/body editing
- Clear/reset day mindmap nodes

## Phase 2: Capture and templates

Status: in progress.

- Template library: daily plan, meeting, project brief, goal/OKR, weekly review
- Slash commands in node body (`/task`, `/goal`, `/plan`, `/meeting`, `/link`, `/today`)
- Quick capture inbox: title + body/context from quick-create sheet
- Convert text/body to checklist or plan steps

## Phase 3: Views and databases

Status: in progress.

- Table view for day node properties
- Saved filters/views
- Board view by status/project
- Timeline/time-block view upgrades
- Tag detail page and tag cloud

## Phase 4: Graph power tools

- Relation labels: depends, supports, blocks, references, part of
- Node groups/frames
- Auto layout: tidy, radial, by type, by dependency
- Focus mode: selected node neighborhood only
- Relation path breadcrumbs

## Phase 5: Reviews and productivity systems

- Daily/weekly/monthly review dashboards
- Inbox zero workflow
- Eisenhower matrix
- Pomodoro/focus sessions
- Habit streaks and recovery
- Goal/OKR health
- Project health score

## Phase 6: Knowledge and attachments

- Markdown preview
- Block references
- Node aliases
- Attachments and link previews
- Resource reading queue

## Phase 7: Smart automation

- Auto-link suggestions
- Natural language node creation
- Day/week/project summaries
- Checklist/plan extraction from notes
- Smart scheduling suggestions
